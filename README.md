## 使い方

`index.html` をブラウザで開くだけで動作します（ビルド不要）。GitHub Pages で公開する場合は、リポジトリの Settings → Pages でこのブランチのルートを指定してください。

- 各トピックの「読了にする」で進み具合を記録できます（ブラウザの localStorage に保存）
- ライト／ダークの配色切替に対応
- スマートフォン表示に対応（目次はボタンで開閉）

内容は2026年9月時点の公開情報にもとづきます。実務では最新の一次資料を確認してください。
